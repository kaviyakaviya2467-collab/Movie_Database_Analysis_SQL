# Movie_Database_Analysis_SQL

#  Movie Dataset – SQL Practice

##  Overview
A MySQL SQL practice project based on a movie dataset.  
The project focuses on retrieving, filtering, sorting, and analyzing movie data using SQL queries.

##  Objective
To practice SQL concepts and gain hands-on experience in analyzing structured movie data.

##  Tools Used
- MySQL
- MySQL Workbench
- SQL

##  Dataset
The `movies` table contains:
- Movie Name
- Release Year
- Actor
- Language
- Director

##  SQL Concepts
- SELECT & WHERE
- DISTINCT
- LIKE & BETWEEN
- ORDER BY & LIMIT
- COUNT()
- GROUP BY
- HAVING
- Aggregate Functions
